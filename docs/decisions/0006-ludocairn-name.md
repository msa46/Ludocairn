# 0006: Adopt Ludocairn as the Product Name

- Status: accepted
- Date: 2026-08-21

## Context

The project's original working name, Deckwright, was already used by several
unrelated products, including card-game and software services. The project
owner confirmed that they did not own or control those uses. Continuing under
that name would create avoidable confusion for a public repository.

## Decision

Adopt `Ludocairn` as the working product and package name, pronounced
`LOO-doh-kairn`. The coined name combines an association with play (`ludo`)
and a durable guide marker (`cairn`). Use a descriptive tabletop-game tagline
while the invented name is unfamiliar.

Record the dated preliminary search in
[`docs/name-clearance.md`](../name-clearance.md). Do not use a registered-mark
symbol or describe the name as legally guaranteed, registered, or formally
cleared.

## Alternatives considered

Keeping Deckwright was rejected because overlapping active uses were found.
Turnweave, Ruleweave, Tablore, and Turnfolio were rejected after finding active
software or service uses. A purely descriptive name would be easier to
understand immediately but harder to distinguish and search.

## Consequences

Current application copy, package metadata, documentation, and original game
authorship use Ludocairn. Historical foundation records retain the former name
with a supersession note so their original context remains clear. The GitHub
repository can be renamed separately after the new build is complete and
verified, avoiding disruption to the currently published Pages site.
