# Ludocairn Preliminary Name Screening

- Search date: 2026-08-21
- Candidate: `Ludocairn`
- Pronunciation: `LOO-doh-kairn`
- Intended use: an open-source static web application for tabletop game rules,
  card references, local session tracking, printing, and session files

## Why this name

`Ludocairn` is a coined word combining *ludo*, associated with play and games,
with *cairn*, a durable guide marker. The combination fits a tool that helps a
table find, understand, and track a game while remaining distinctive enough to
search effectively. The public tagline should explain the product until the
invented name becomes familiar.

## Limits and follow-up

This is a preliminary conflict screen, not a legal opinion or a guarantee of
registrability or freedom to use. Trademark rights may arise without an exact
database match, database coverage changes, and domain availability can change.
Obtain professional clearance before material commercial investment.

The project must not use the registered-trademark symbol, claim registration,
or imply affiliation with another game or software publisher. Recheck the name
before a major commercial launch, paid promotion, or trademark application.
